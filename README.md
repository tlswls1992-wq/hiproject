# 가챠 용사

> 왕에게 마왕을 무찌르라는 명령을 받은 용사. 그런데 용사가 가진 힘은 단 하나, **가챠(뽑기)** 뿐이었다!

뽑기로 동료를 모아 선두~후미 5줄 진형으로 파티를 꾸리고, 오른쪽에서 몰려오는 마왕군과 싸우며 100개의 판을 공략하는 **2D 고정 화면 오토배틀러**예요.
([Legionbound](https://store.steampowered.com/app/4283360/Legionbound/)에서 영감을 받았어요.)

> 지금은 **프로토타입**이에요. 그림 대신 동그라미와 네모로 표시돼요. 게임 흐름과 재미를 먼저 확인하는 단계예요.

---

## 🎮 실행하는 방법

### 처음 한 번: Unity 프로젝트 만들기
1. **Unity Hub**를 실행하고 **New project**를 눌러요.
2. 템플릿에서 **Universal 2D**를 골라요. 없으면 **2D**를 골라도 돼요.
3. 이름(예: `GachaHero`)을 쓰고 **Create project**를 눌러요.

### 스크립트와 그림 넣기 (업데이트할 때마다)
1. 이 저장소의 GitHub 페이지에서 브랜치를 `claude/lucid-hawking-ne6ep1`로 바꿔요.
2. 초록색 **Code** 버튼을 누르고 **Download ZIP**을 받아 압축을 풀어요.
3. Unity의 **Project** 창에 이미 `Scripts`, `Resources` 폴더가 있으면, 오른쪽 클릭 → **Delete**로 먼저 지워요.
4. 압축을 푼 폴더의 `Assets` 안에 있는 **`Scripts`** 폴더와 **`Resources`** 폴더를 Unity의 **Project** 창 **Assets** 위로 끌어다 놓아요.
   - `Resources` 폴더에는 캐릭터 그림이 들어 있어요. 이 폴더 이름은 꼭 `Resources`여야 게임이 그림을 찾을 수 있어요.
5. 오른쪽 아래의 빙글빙글이 멈추면 맨 위 **▶ (Play)** 버튼을 눌러요.

> 💡 따로 설정할 건 없어요. ▶를 누르면 타이틀 화면이 나와요.

## 🕹️ 게임 흐름

```
타이틀 ─ 새로 시작 → 오프닝 → 첫 소환 (무료 동료 2명) → 야영지
       ├ 이어하기 / 불러오기 → 야영지
       ├ 설정
       └ 끝내기

야영지 ⇄ 소환 / 편성 / 동료(성급 강화·판매) / 도감 / 전승 특전 / 저장 / 설정
 ↓ 출격
(스테이지 보스면 보스 대사 컷씬) → 전투 → 결과 → 야영지 또는 다음 라운드
```

| 화면 | 할 수 있는 것 |
|---|---|
| **야영지** | 모닥불 주위에 출진 중인 동료들이 앉아 있어요. **누르면 말을 걸 수 있어요.** 왼쪽에서 라운드를 고르고 출격해요 |
| **소환** | 일반 / 고급 / 전설 / 신화 뽑기. 1회 또는 10회 |
| **편성** | 선두~후미 5개의 줄에 동료를 끌어다 원하는 위치에 놓아요 |
| **동료** | 같은 캐릭터를 합쳐 **성급 강화**를 하거나, 동료를 **판매**해서 골드로 바꿔요 |
| **도감** | **인물 / 적 / 아이템(준비 중)** 탭으로 나뉘어 있어요 |
| **전승 특전** | 회차를 클리어하면 열려요. 호감도를 올리고 다음 회차를 시작해요 |
| **설정** | 대사 속도, 전투 시작 배속(x1~x4), 창 모드/전체 화면 |

### 캐릭터
- **등급:** 노말 < 레어 < 슈퍼레어 < 유니크 < 전설 < 신화
- **기본 설정:** 모든 캐릭터는 **[종족 / 소속 / 직업 / 성향]**을 가져요. 성향은 혼돈 · 중립 · 질서 · 명예 · 실리 · 선 · 악이에요.
- **직업:** 하급 병사 · 전사 · 궁수 · 마법사 · 사제 (+ 용사 전용 직업 '용사')
- **같은 인물은 한 명만 배치:** 발로, 드보람처럼 **이름이 있는 캐릭터**는 여러 명 가지고 있어도 **파티에는 한 명만** 배치할 수 있어요. 이름 없는 일반 캐릭터(마을 청년, 사냥꾼 등)는 여러 명 배치할 수 있어요.

| 캐릭터 | 등급 | 종족 / 소속 / 직업 / 성향 |
|---|---|---|
| 용사 | 유니크 | 인간 / 용사 파티 / 용사 / 중립 |
| 발로 | 노말 | 인간 / 올 왕국 / 하급 병사 / 선 |
| 드보람 | 노말 | 인간 / 올 왕국 / 하급 병사 / 실리 |

### 성장: 성급 > 레벨
| 방법 | 효과 | 얻는 법 |
|---|---|---|
| **성급 (★)** | ★ 하나마다 능력치 **+30%** (최대 5성) | **동료** 화면에서 같은 캐릭터를 재료로 합치기. 재료의 ★·레벨과 상관없이 **같은 캐릭터면 합칠 수 있어요.** 예) 발로 + 발로 → 발로 2성 (재료는 사라짐) |
| **레벨** | 레벨 하나마다 능력치 **+2%** (최대 Lv.30) | 전투에 나가면 경험치를 얻어요 (이기면 많이, 져도 조금) |
| **각성** (용사만) | 각성 하나마다 **+10%** (최대 +10) | 뽑기에서 용사 카드(유니크)가 나오면 |
| **호감도 ♥** (용사 제외) | 호감도 하나마다 **+5%** | 전승 특전에서 올려요 |

- **판매:** 동료를 팔면 골드를 받아요 (등급이 높고 ★이 많을수록 비쌈). **용사는 팔 수 없어요.**

### 편성 (선두 · 전열 · 중열 · 후열 · 후미)
- 목록에서 동료를 **끌어서 줄 안의 원하는 위치에** 놓아요. 한 줄에 최대 5명이에요.
- **출진 가능 인원:** 처음 **7명**(용사 포함)이고, **스테이지를 클리어할 때마다 1명씩** 늘어요.
- 용사는 항상 출진해요. 위치만 옮길 수 있어요.

### 소환 (가챠)
| 뽑기 | 가격 (1회 / 10회) | 열리는 조건 | 10회 보장 |
|---|---|---|---|
| 일반 뽑기 | 100 / 900 골드 | 처음부터 | 레어 이상 |
| 고급 뽑기 | 300 / 2,700 골드 | 처음부터 | 슈퍼레어 이상 |
| 전설 뽑기 | 1,000 / 9,000 골드 | 2-10 클리어 | 유니크 이상 |
| 신화 뽑기 | 3,000 / 27,000 골드 | 5-10 클리어 | 전설 이상 |

### 전투
- **근거리 동료는 적에게 다가가서**, **원거리 동료는 사거리까지 다가가서** 공격해요. 사제는 다친 아군을 치유해요.
- **용사를 포함한 파티원이 모두 쓰러지면 패배**예요. 웨이브 3개를 모두 물리치면 승리예요.
- 웨이브 사이에는 **전투 보너스**를 하나 골라요 (이번 판 동안만 유지).
- 전투 속도는 **x1 → x2 → x3 → x4** (버튼을 누를 때마다 바뀜).
- 같은 직업이 **3명 / 6명** 모이면 **시너지**가 켜져요.

### 스테이지 (10스테이지 × 10라운드 = 100판)
- 각 스테이지의 **5라운드에는 중간 보스**, **10라운드에는 스테이지 보스**가 나와요.
- 스테이지 보스 전에는 **보스 대사 컷씬**이 나와요. 그 보스를 **한 번 이기면** 다음부터 컷씬에 **건너뛰기** 버튼이 생겨요.

| 스테이지 | 이름 | 중간 보스 (x-5) | 스테이지 보스 (x-10) |
|---|---|---|---|
| 1 | 올 왕국 외곽 숲 | 숲 도적 두목 | 거대 멧돼지 왕 |
| 2 | 동부 평원 | 평원 늑대 우두머리 | 켄타우로스 족장 |
| 3 | 올드락 산맥 | 산적 대장 | 바위 거인 |
| 4 | 카니 해안 | 해적 갑판장 | 거대 게 카니 |
| 5 | 포빌리아 왕국 검문소 | 검문소 경비대장 | 포빌리아 기사단장 |
| 6 | 은혜의 땅 | 타락한 수도사 | 거짓 성자 |
| 7 | 노란 용의 굴 | 새끼 황룡 | 노란 용 |
| 8 | 붉은 정글 | 정글 주술사 | 붉은 표범 여왕 |
| 9 | 옛 대전쟁터 | 망령 기사 | 전쟁의 망령 장군 |
| 10 | 마왕성 | 마왕군 사천왕 | **마왕** (쓰러뜨리면 엔딩) |

(보스 이름과 대사는 임시예요. `Stages.cs`에서 바꿀 수 있어요.)

### 회차와 전승 특전
1. 10-10에서 마왕을 쓰러뜨리면 엔딩을 보고 **회차 클리어**! 야영지에 **전승 특전**이 열려요.
2. 전승 특전에서는 이번 회차에 캐릭터가 도달한 **레벨 10마다 호감도를 1** 올릴 수 있어요. (30레벨이면 3)
3. **다음 회차 시작**을 누르면 동료 · 골드 · 진행은 처음부터 다시 시작하고, **호감도와 적 도감은 이어져요.**

진행 상황은 자동으로 저장돼요.

## 🎨 캐릭터 그림

그림이 있는 캐릭터는 그림으로, 없는 캐릭터는 지금처럼 동그라미로 나와요. 지금은 **용사** 그림이 들어 있어요.

| 그림 | 쓰이는 곳 | 파일 |
|---|---|---|
| **전신** | 뽑기 카드, 동료 화면 카드, 오프닝의 "헤헤" 장면 | `full.png` |
| **초상화** | 도감, 야영지 대화, 스토리 대화, 동료 목록 | `portrait.png` |
| **프리뷰 (대기)** | 야영지에 앉아 있는 모습, 편성 화면, 전투 중 대기 | `idle/idle_00.png` … |
| **어택 (공격)** | 전투에서 공격할 때 (움직이는 그림) | `attack/attack_00.png` … |

- 위치: `Assets/Resources/Characters/<캐릭터 id>/` (용사는 `hero`, 발로는 `n_balo` …; id는 `CompanionData.cs`에 있어요)
- 원본 그림은 `Art/originals/<캐릭터 id>/`에 보관해요.
- **새 캐릭터 그림을 넣고 싶으면** 4장(전신, 초상화, 프리뷰, 어택)을 Claude에게 보내 주세요. Unity가 읽을 수 있는 png로 바꾸고, 배경을 지우고, 움직이는 그림(gif)은 장면별로 나눠서 넣어 드려요.
- 전투에서 그림 크기를 바꾸려면 `CharacterArt.cs`의 `BattleCanvasHeight` 숫자를 바꾸세요.
