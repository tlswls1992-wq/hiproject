# 가챠 용사

> 왕에게 마왕을 무찌르라는 명령을 받은 용사. 그런데 용사가 가진 힘은 단 하나, **가챠(뽑기)** 뿐이었다!

뽑기로 동료를 모아 5줄 진형으로 파티를 꾸리고, 오른쪽에서 몰려오는 마왕군과 싸우며 100개의 판을 공략하는 **2D 고정 화면 오토배틀러**예요.
([Legionbound](https://store.steampowered.com/app/4283360/Legionbound/)에서 영감을 받았어요.)

> 지금은 **프로토타입**이에요. 그림 대신 동그라미와 네모로 표시돼요. 게임 흐름과 재미를 먼저 확인하는 단계예요.

---

## 🎮 실행하는 방법

### 처음 한 번: Unity 프로젝트 만들기
1. **Unity Hub**를 실행하고 **New project**를 눌러요.
2. 템플릿에서 **Universal 2D**를 골라요. 없으면 **2D**를 골라도 돼요.
3. 이름(예: `GachaHero`)을 쓰고 **Create project**를 눌러요.

### 스크립트 넣기 (업데이트할 때마다)
1. 이 저장소의 GitHub 페이지에서 브랜치를 `claude/lucid-hawking-ne6ep1`로 바꿔요.
2. 초록색 **Code** 버튼을 누르고 **Download ZIP**을 받아 압축을 풀어요.
3. Unity의 **Project** 창에 이미 `Scripts` 폴더가 있으면, 오른쪽 클릭 → **Delete**로 먼저 지워요.
4. 압축을 푼 폴더의 `Assets/Scripts` 폴더를 Unity의 **Project** 창 **Assets** 위로 끌어다 놓아요.
5. 오른쪽 아래의 빙글빙글이 멈추면 맨 위 **▶ (Play)** 버튼을 눌러요.

> 💡 따로 설정할 건 없어요. ▶를 누르면 타이틀 화면이 나와요.

## 🕹️ 게임 흐름

```
타이틀 → 스토리 → 첫 소환 (무료 동료 2명) → 캠프 ⇄ 소환 / 편성 / 도감
                                              ↓
                                         출격 → 전투 → 결과 → 캠프
```

| 화면 | 할 수 있는 것 |
|---|---|
| **스토리** | 화면을 클릭하면 대사가 넘어가요. 오른쪽 위 "건너뛰기"로 생략할 수 있어요 |
| **캠프** | ◀ ▶(한 판씩), ◀◀ ▶▶(스테이지씩)로 판을 고르고 **출격**해요 |
| **소환** | 일반 / 고급 / 전설 / 신화 뽑기. 1회 또는 10회 뽑기 |
| **편성** | 5줄 × 5칸에 동료를 **끌어다 놓아요**. 칸끼리 끌면 자리를 바꾸고, 목록으로 끌면 빠져요 |
| **도감** | 뽑은 동료를 모아 봐요. 못 뽑은 동료는 ?로 보여요 |
| **전투** | 자동으로 싸워요. 웨이브 사이마다 **강화 카드**를 골라요 |

### 용사
- 용사는 **항상 파티에 있어요**. 편성에서 자리만 옮길 수 있어요.
- 용사도 직접 싸우는 **파티원**이에요 (근접 · 만능형).
- 뽑기에서 **용사 카드**(영웅 등급)가 나올 수 있어요. 나오면 용사가 **각성**해서 능력치가 10%씩 올라요 (최대 +10). 최대 각성 뒤에는 골드 300으로 바꿔 줘요.

### 편성 (5줄 × 5칸)
```
        후미   후열   중열   전열   선두      적 →
윗줄    [  ]   [  ]   [  ]   [  ]   [  ]
 ...    [  ]   [  ]   [  ]   [  ]   [  ]   (줄마다 5칸, 최대 25명)
아랫줄  [  ]   [  ]   [  ]   [  ]   [  ]
```
- 동료는 **놓은 칸에서 움직이지 않고** 싸워요. 사거리 안에 적이 들어오면 공격해요.
- 근접 동료(전사, 용사)는 앞줄, 원거리 동료(궁수, 마법사)와 사제는 뒷줄에 두는 게 좋아요.
- 적은 5개의 줄을 따라 오른쪽에서 걸어와요.
- "자동 배치"를 누르면 직업에 맞게 알아서 배치해 줘요.

### 소환 (가챠)
| 뽑기 | 가격 (1회 / 10회) | 열리는 조건 | 10회 보장 |
|---|---|---|---|
| 일반 뽑기 | 100 / 900 골드 | 처음부터 | 희귀 이상 |
| 고급 뽑기 | 300 / 2,700 골드 | 처음부터 | 영웅 이상 |
| 전설 뽑기 | 1,000 / 9,000 골드 | 2-10 클리어 | 전설 이상 |
| 신화 뽑기 | 3,000 / 27,000 골드 | 5-10 클리어 | 전설 이상 |

- **연출:** 마법진이 돌다가 좋은 등급이 나오면 빛의 색이 바뀌어요 (영웅은 보라, 전설은 금색, 신화는 무지개). 뒤집힌 카드를 눌러 하나씩 열고, 전설 이상이면 화면이 번쩍여요.
- **등급:** 일반 ★ < 희귀 ★★ < 영웅 ★★★ < 전설 ★★★★ < 신화 ★★★★★. 등급이 높을수록 능력치가 배로 강해져요 (일반의 1배 → 신화 4.5배).

### 전투
- **용사를 포함한 파티원이 모두 쓰러지면 패배**예요. 웨이브 3개를 모두 막으면 승리예요.
- **"도망쳐 용사!"** 버튼을 누르면 전투에서 도망쳐요. 그때까지 번 골드는 받아요.
- 같은 직업이 **3명 / 6명** 모이면 **시너지**가 켜져요:
  - 🔵 전사: 받는 피해 감소 · 🟢 궁수: 공격 속도 증가 · 🟣 마법사: 폭발 범위 증가 · 🟡 사제: 치유량 증가
- 처음 클리어하면 보상이 2배예요. 뽑은 동료는 지거나 도망쳐도 그대로 남아요.

### 스테이지 (10스테이지 × 10판 = 100판)
| 스테이지 | 이름 | 보스 (x-10) |
|---|---|---|
| 1 | 왕국의 초원 | 고블린 왕 |
| 2 | 속삭이는 숲 | 거대 늑대 |
| 3 | 버려진 광산 | 광산 골렘 |
| 4 | 사막의 유적 | 미라 왕 |
| 5 | 얼어붙은 설원 | 서리 거인 |
| 6 | 독안개 늪지 | 늪의 히드라 |
| 7 | 불타는 화산 | 화염 군주 |
| 8 | 망자의 묘지 | 리치 |
| 9 | 마왕군 요새 | 어둠의 기사 |
| 10 | 마왕성 | **마왕** (10-10, 쓰러뜨리면 엔딩) |

진행 상황(골드, 동료, 편성, 클리어한 판)은 자동으로 저장돼요.

## 🛠️ 직접 바꿔 보기 (코딩 몰라도 OK)

Project 창에서 파일을 더블클릭하면 코드 편집기가 열려요. 숫자나 글자를 바꾸고 저장(Ctrl+S)한 뒤 다시 ▶를 누르면 돼요.

| 바꾸고 싶은 것 | 파일 |
|---|---|
| 동료 추가 / 이름 / 설명 | `CompanionData.cs`의 `All` 목록 |
| 등급별 능력치 배수, 등급 색 | `CompanionData.cs` 위쪽 |
| 직업별 기본 능력치 | `HeroClass.cs` |
| 뽑기 가격, 확률, 해금 조건 | `Gacha.cs` |
| 스테이지 이름, 보스 이름, 보상, 색 | `Stages.cs` |
| 스토리 대사 | `GameManager.cs`의 `OpeningStory`, `EndingStory` |
| 용사 능력치 | `HeroClass.cs`의 `Brave` |
| 적 능력치, 각성 보너스, 칸 간격 | `BattleManager.cs` |

## 📁 파일 구성

| 파일 | 하는 일 |
|---|---|
| `GameManager.cs` | 게임 흐름과 화면 (타이틀, 스토리, 캠프, 소환 선택, 편성, 도감, 결과) |
| `GachaScreen.cs` | 뽑기 연출 (마법진, 카드 뒤집기) |
| `Gacha.cs` | 뽑기 종류, 확률, 10회 보장 |
| `CompanionData.cs` | 동료 목록과 등급 |
| `HeroClass.cs` | 직업 (전사, 궁수, 마법사, 사제) |
| `BattleManager.cs` | 전투 (5x5 칸 배치, 웨이브, 보스, 시너지, 강화 카드, 전투 화면) |
| `Unit.cs` | 동료와 적의 이동, 공격, 치유 |
| `Stages.cs` | 스테이지 정보 (10스테이지 × 10판) |
| `SaveData.cs` | 저장하기와 불러오기, 편성 칸, 자동 배치, 용사 각성 |
| `UI.cs` | 버튼과 글자 그리기 도우미 |
| `Projectile.cs` / `FadeOut.cs` / `SpriteFactory.cs` | 화살, 효과, 임시 그림 |
