# 가챠 용사

> 왕에게 마왕을 무찌르라는 명령을 받은 용사. 그런데 용사가 가진 힘은 단 하나, **가챠(뽑기)** 뿐이었다!

뽑기로 동료를 모아 선두~후미 5줄 진형으로 파티를 꾸리고, 오른쪽에서 몰려오는 마왕군과 싸우며 100개의 판을 공략하는 **2D 고정 화면 오토배틀러**예요.
([Legionbound](https://store.steampowered.com/app/4283360/Legionbound/)에서 영감을 받았어요.)

> 지금은 **프로토타입**이에요. 그림 대신 동그라미와 네모로 표시돼요. 게임 흐름과 재미를 먼저 확인하는 단계예요.

---

## 🎮 실행하는 방법

### 처음 한 번: Unity 프로젝트 만들기
1. **Unity Hub**를 실행하고 **New project**를 눌러요.
2. 템플릿에서 **Universal 2D**를 골라요. 없으면 **2D**를 골라도 돼요.
3. 이름(예: `GachaHero`)을 쓰고 **Create project**를 눌러요.

### 스크립트와 그림 넣기 (업데이트할 때마다)
1. 이 저장소의 GitHub 페이지에서 브랜치를 `claude/lucid-hawking-ne6ep1`로 바꿔요.
2. 초록색 **Code** 버튼을 누르고 **Download ZIP**을 받아 압축을 풀어요.
3. Unity의 **Project** 창에 이미 `Scripts`, `Resources` 폴더가 있으면, 오른쪽 클릭 → **Delete**로 먼저 지워요.
4. 압축을 푼 폴더의 `Assets` 안에 있는 **`Scripts`** 폴더와 **`Resources`** 폴더를 Unity의 **Project** 창 **Assets** 위로 끌어다 놓아요.
   - `Resources` 폴더에는 캐릭터 그림, 배경, 글꼴, 소리가 들어 있어요. 이 폴더 이름은 꼭 `Resources`여야 게임이 그림을 찾을 수 있어요.
5. 오른쪽 아래의 빙글빙글이 멈추면 맨 위 **▶ (Play)** 버튼을 눌러요.

> 💡 따로 설정할 건 없어요. ▶를 누르면 타이틀 화면이 나와요.

## 🕹️ 게임 흐름

```
타이틀 ─ 새로 시작 → 오프닝 → 첫 소환 (무료 동료 2명) → 야영지
       ├ 이어하기 / 불러오기 → 야영지
       ├ 설정
       └ 끝내기

야영지 ⇄ 소환 / 편성 / 동료(성급 강화·판매) / 도감 / 전승 특전 / 저장 / 설정
 ↓ 출격
전투 (스테이지 첫 라운드는 맵 입장 멘트, 보스가 나오면 보스 대사) → 결과 → 야영지 또는 다음 라운드 (스테이지 보스를 이기면 엔딩 선택지로 다음 목적지를 고르고, 지면 야영지)
```

|---|---|
| **야영지** | 모닥불 주위에 출진 중인 동료들이 앉아 있어요. **누르면 말을 걸 수 있어요.** 왼쪽에서 라운드를 고르고 출격해요 |
| **소환** | 일반 / 고급 / 전설 / 신화 뽑기. 1회 또는 10회 |

| **동료** | 같은 캐릭터를 합쳐 **성급 강화**를 하거나, 동료를 **판매**해서 골드로 바꿔요. 오른쪽 아래 **일괄 합성**으로 한 번에 합칠 수 있어요 |

### 캐릭터
- **등급:** 노말 < 레어 < 슈퍼레어 < 유니크 < 전설 < 신화
- **기본 설정:** 모든 캐릭터는 **[종족 / 소속 / 직업 / 성향]**을 가져요. 성향은 혼돈 · 중립 · 질서 · 명예 · 실리 · 선 · 악이에요.
- **직업:** 근접(하급 병사 · 창병 · 기사 · 용병 · 모험가 · 감찰관 · 짐꾼), 원거리(궁수 · 마법사 · 폴리모프 용), 치유(성녀 · 힐러), 용사 전용 '용사'. 직업별 능력치는 아직 **임시값**이에요.
- **같은 인물은 한 명만 배치:** 지금 동료는 모두 **이름이 있는 인물**이라, 여러 명 가지고 있어도 **파티에는 한 명만** 배치할 수 있어요.
- **인물 설정은 내부용:** 각 캐릭터의 인물 설정은 `CompanionData.cs`에 메모(`note`)로만 있고 게임 화면에는 나오지 않아요. 캠프 대화의 말투에만 살짝 묻어나요.

### 성장: 성급 > 레벨
| 방법 | 효과 | 얻는 법 |
|---|---|---|
| **성급 (★)** | ★ 하나마다 능력치 **+30%** (최대 5성). **용사는 뽑기에서 용사 카드가 나오면** 성급이 올라가요 | **동료** 화면에서 같은 캐릭터를 재료로 합치기. 재료의 ★·레벨과 상관없이 **같은 캐릭터면 합칠 수 있어요.** 예) 발로 + 발로 → 발로 2성 (재료는 사라짐) |
| **레벨** | 레벨 하나마다 능력치 **+2%** (최대 Lv.30) | 전투에 나가면 경험치를 얻어요 (이기면 많이, 져도 조금) |
| **호감도 ♥** (용사 제외) | 호감도 하나마다 **+5%** | 전승 특전에서 올려요 |

- **판매:** 동료를 팔면 골드를 받아요 (등급이 높고 ★이 많을수록 비쌈). **용사는 팔 수 없어요.**

### 편성 (선두 · 전열 · 중열 · 후열 · 후미)
- 목록에서 동료를 **끌어서 줄 안의 원하는 위치에** 놓아요. 한 줄에 최대 5명이에요.
- **출진 가능 인원:** 처음 **7명**(용사 포함)이고, **스테이지를 클리어할 때마다 1명씩** 늘어요.
- 용사는 항상 출진해요. 위치만 옮길 수 있어요.

### 전투
- 웨이브가 시작되면 **적이 처음부터 오른쪽에 진을 치고** 있어요. 파티가 **접근 거리 안**으로 다가가면 그때부터 싸워요. (적은 맞거나 싸우기 시작하면 끝까지 쫓아와요)
- **근거리 동료는 적에게 다가가서**, **원거리 동료는 사거리까지 다가가서** 공격해요. 성녀·힐러는 다친 아군을 치유해요.
- **용사를 포함한 파티원이 모두 쓰러지면 패배**예요. 웨이브 2개(웨이브 1 → 웨이브 2)를 모두 물리치면 승리예요. 보스는 웨이브 2에 나와요.
- 웨이브는 **기다리지 않고 바로** 시작해요. 웨이브 1을 이기면 **전투 보너스**를 하나 골라요 (이번 판 동안만 유지, 예: 공격력 +8%, 체력 50% 회복).
- 같은 **소속** 동료가 **2명 / 4명** 모이면 **소속 시너지**가 켜져요. (용사는 숫자에 안 들어가지만 '용사 파티' 효과는 받아요. 효과는 그 소속 동료에게만 적용돼요)
  - 용사 파티: 공격력·치유량 +15% / +30%
  - 올 왕국: 받는 피해 -12% / -24%
  - 자유 용병: 공격 속도 +15% / +30%

### 스테이지 (10스테이지 × 10라운드 = 100판)
- **1~4라운드**는 전반 적, **5라운드**는 전반 적 + **중간 보스**, **6~9라운드**는 후반 적, **10라운드**는 후반 적 + **최종 보스**가 나와요.
- 보스는 **일반 적과 함께** 웨이브 2에 나와요. 이름 옆 **(1)** 인물은 다른 적과 섞여 나오되 **한 전투에 한 명만** 나와요.
- **대사는 사념파처럼** 전투 화면 위에 한 줄씩 떠올라요. (전투는 그동안 멈춤)
  - 스테이지 1라운드: **맵 입장 멘트**
  - 보스가 나타날 때: **보스 대사**. 보스 전신 그림(`Resources/Enemies/<적 id>/full.png`)이 있으면 오른쪽에 나와요.
  - 클릭하면 다음 줄, 다 나오면 닫혀요. 그 스테이지를 한 번 깨면 **건너뛰기** 버튼이 생겨요.

### 🔊 소리
- **배경음악 3곡**(야영지, 전투, 보스)과 **효과음**(베기, 찌르기, 묵직한 일격, 물기, 화살, 마법, 폭발, 치유, 쓰러짐, 뽑기, 높은 등급 뽑기, 승리, 패배, 버튼, 사념파 대사)이 있어요.
- 모든 소리는 `Art/make_audio.py`가 **수학 공식(사인파·노이즈)으로 직접 합성**한 것이라 외부 음원을 쓰지 않아 **저작권 걱정이 없어요.**
- 음량은 **설정**에서 배경음악 / 효과음 따로 바꿀 수 있어요 (끔 ~ 100%).

### 회차와 전승 특전
1. 10-10에서 마왕을 쓰러뜨리면 엔딩을 보고 **회차 클리어**! 야영지에 **전승 특전**이 열려요.
2. 전승 특전에서는 이번 회차에 캐릭터가 도달한 **레벨 10마다 호감도를 1** 올릴 수 있어요. (30레벨이면 3)
3. **다음 회차 시작**을 누르면 동료 · 골드 · 진행은 처음부터 다시 시작하고, **호감도와 적 도감은 이어져요.**

진행 상황은 자동으로 저장돼요.

## 🎨 캐릭터 그림

그림이 있는 캐릭터는 그림으로, 없는 캐릭터는 지금처럼 동그라미로 나와요. 지금은 **용사** 그림이 들어 있어요.

| 그림 | 쓰이는 곳 | 파일 |
|---|---|---|
| **전신** | 뽑기 카드, 오프닝의 "헤헤" 장면 | `full.png` |
| **초상화** | 도감, 동료 화면, 야영지 대화, 스토리 대화, 목록 아이콘 | `portrait.png` |
| **프리뷰 (대기)** | 야영지, 편성 화면, 전투 중 대기 (한 장이면 숨 쉬듯 살짝 움직여요) | `idle/idle_00.png` … |
| **달리기** | 전투 중 이동 (여러 장면이면 그대로 재생, 한 장이면 살짝 오르내려요. 여러 장면을 격자로 모은 장면표도 돼요: 원본 이름을 `run_sheet_4x2`처럼 가로x세로 칸 수로 지어 주세요) | `run/run_00.png` … |
| **어택 (공격)** | 전투에서 공격할 때 (움직이는 그림) | `attack/attack_00.png` … |

- 위치: `Assets/Resources/Characters/<캐릭터 id>/` (용사는 `hero`, 발로는 `n_balo` …; id는 `CompanionData.cs`에 있어요)
- 원본 그림은 `Art/originals/<캐릭터 id>/`에 보관해요.
- 전투에서는 **공격 → 달리기 → 대기** 순서로 동작이 정해져요. 공격 중이면 공격, 움직이고 있으면 달리기, 아니면 대기 동작이 나와요. 동작마다 발 높이를 맞춰 두어서 바뀔 때 들썩이지 않아요.
- **새 캐릭터 그림을 넣고 싶으면** 5장(전신, 초상화, 프리뷰, 달리기, 어택)을 Claude에게 보내 주세요. Unity가 읽을 수 있는 png로 바꾸고, 배경을 지우고, 움직이는 그림(gif)은 장면별로 나눠서 넣어 드려요.
- 전투에서 그림 크기를 바꾸려면 `CharacterArt.cs`의 `BattleCanvasHeight` 숫자를 바꾸세요.
