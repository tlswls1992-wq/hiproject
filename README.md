# 가챠 용사

> 왕에게 마왕을 무찌르라는 명령을 받은 용사. 그런데 용사가 가진 힘은 단 하나, **가챠(뽑기)** 뿐이었다!

뽑기로 동료를 모아 선두~후미 5줄 진형으로 파티를 꾸리고, 오른쪽에서 몰려오는 마왕군과 싸우며 100개의 판을 공략하는 **2D 고정 화면 오토배틀러**예요.
([Legionbound](https://store.steampowered.com/app/4283360/Legionbound/)에서 영감을 받았어요.)

> 지금은 **프로토타입**이에요. 그림 대신 동그라미와 네모로 표시돼요. 게임 흐름과 재미를 먼저 확인하는 단계예요.

---

## 🎮 실행하는 방법

### 처음 한 번: Unity 프로젝트 만들기
1. **Unity Hub**를 실행하고 **New project**를 눌러요.
2. 템플릿에서 **Universal 2D**를 골라요. 없으면 **2D**를 골라도 돼요.
3. 이름(예: `GachaHero`)을 쓰고 **Create project**를 눌러요.

### 스크립트 넣기 (업데이트할 때마다)
1. 이 저장소의 GitHub 페이지에서 브랜치를 `claude/lucid-hawking-ne6ep1`로 바꿔요.
2. 초록색 **Code** 버튼을 누르고 **Download ZIP**을 받아 압축을 풀어요.
3. Unity의 **Project** 창에 이미 `Scripts` 폴더가 있으면, 오른쪽 클릭 → **Delete**로 먼저 지워요.
4. 압축을 푼 폴더의 `Assets/Scripts` 폴더를 Unity의 **Project** 창 **Assets** 위로 끌어다 놓아요.
5. 오른쪽 아래의 빙글빙글이 멈추면 맨 위 **▶ (Play)** 버튼을 눌러요.

> 💡 따로 설정할 건 없어요. ▶를 누르면 타이틀 화면이 나와요.

## 🕹️ 게임 흐름

```
타이틀 ─ 새로 시작 → 오프닝 → 첫 소환 (무료 동료 2명) → 캠프
       ├ 이어하기 → 캠프 (자동 저장된 기록)
       ├ 불러오기 → 슬롯 선택 → 캠프
       ├ 설정
       └ 끝내기

캠프 ⇄ 소환 / 편성 / 강화 / 대화 / 도감 / 저장 / 설정
 ↓
출격 → 전투 → 결과 → 캠프
```

| 화면 | 할 수 있는 것 |
|---|---|
| **타이틀** | 새로 시작 · 이어하기 · 불러오기 · 설정 · 끝내기 |
| **오프닝** | 화면을 클릭하면 대사가 넘어가요. **오프닝을 본 적이 있으면** 오른쪽 위에 "건너뛰기"가 나와요 |
| **캠프** | ◀ ▶(한 판씩), ◀◀ ▶▶(스테이지씩)로 판을 고르고 **출격**해요 |
| **소환** | 일반 / 고급 / 전설 / 신화 뽑기. 1회 또는 10회 뽑기 |
| **편성** | 선두~후미 5개의 줄에 동료를 **끌어다 원하는 위치에** 놓아요 |
| **강화** | 골드로 캐릭터의 레벨을 올려요 (레벨당 능력치 +8%, 최대 Lv.20). 같은 캐릭터가 여러 명이면 모두 함께 강해져요 |
| **대화** | 동료를 골라 이야기를 나눠요. 용사, 발로, 드보람은 전용 대사가 있고, 다른 동료는 성향에 맞는 대사를 해요 |
| **도감** | 뽑은 동료를 모아 봐요. 못 뽑은 동료는 ?로 보여요 |
| **저장** | 슬롯 1~3에 지금 기록을 저장해요. 진행 상황은 자동 저장도 돼요 |
| **설정** | 대사 속도, 전투 시작 속도(x1/x2), 창 모드/전체 화면 |

### 캐릭터
- **등급:** 노말 ★ < 레어 ★★ < 슈퍼레어 ★★★ < 유니크 ★★★★ < 전설 ★★★★★ < 신화 ★★★★★★
- **기본 설정:** 모든 캐릭터는 **[종족 / 소속 / 직업 / 성향]**을 가져요.
- **성향:** 혼돈 · 중립 · 질서 · 명예 · 실리 · 선 · 악
- **직업:** 하급 병사 · 전사 · 궁수 · 마법사 · 사제 (+ 용사 전용 직업 '용사')

| 캐릭터 | 등급 | 종족 / 소속 / 직업 / 성향 |
|---|---|---|
| 용사 | 유니크 | 인간 / 용사 파티 / 용사 / 중립 |
| 발로 | 노말 | 인간 / 올 왕국 / 하급 병사 / 선 |
| 드보람 | 노말 | 인간 / 올 왕국 / 하급 병사 / 실리 |

(다른 캐릭터들의 설정은 `CompanionData.cs`에서 볼 수 있어요. 지금은 임시로 정한 값이에요.)

- **이름이 있는 캐릭터는 한 명만:** 발로, 드보람처럼 이름이 있는 캐릭터와 슈퍼레어 이상의 캐릭터는 한 번 뽑으면 다시 나오지 않아요.
- **이름 없는 일반 캐릭터**(마을 청년, 사냥꾼, 견습 마법사, 수녀, 용병 검사, 숲의 궁수, 불꽃 마법사, 성당 사제)는 여러 명 뽑을 수 있어요. 목록은 `CompanionData.cs`의 `GenericIds`에서 바꿀 수 있어요.
- 예전 저장에 이름 있는 캐릭터가 여러 명 있으면, 한 명만 남기고 나머지는 1명당 100골드로 돌려줘요.

### 용사
- 용사는 **항상 파티에 있고** 직접 싸워요. 편성에서 위치만 옮길 수 있어요.
- 뽑기에서 **용사 카드(유니크)**가 나오면 용사가 **각성**해서 능력치가 10%씩 올라요 (최대 +10). 최대 각성 뒤에는 골드 300으로 바꿔 줘요.

### 편성 (선두 · 전열 · 중열 · 후열 · 후미)
```
   후미    후열    중열    전열    선두        적 →
  ┌────┐ ┌────┐ ┌────┐ ┌────┐ ┌────┐
  │ ●  │ │    │ │  ● │ │ ●  │ │  ● │
  │    │ │ ●  │ │    │ │    │ │ ●  │   ← 줄 안에서는 원하는 위치에 자유롭게
  │  ● │ │    │ │ ●  │ │  ● │ │  ● │
  └────┘ └────┘ └────┘ └────┘ └────┘
```
- 목록에서 동료를 **끌어서 줄 안의 원하는 위치에** 놓아요. 한 줄에 최대 5명이에요.
- 놓인 동료를 끌어서 위치를 옮기거나, 목록으로 끌어서 뺄 수 있어요 (용사는 뺄 수 없어요).
- "자동 배치"를 누르면 직업에 맞게 알아서 배치해 줘요.

### 소환 (가챠)
| 뽑기 | 가격 (1회 / 10회) | 열리는 조건 | 10회 보장 |
|---|---|---|---|
| 일반 뽑기 | 100 / 900 골드 | 처음부터 | 레어 이상 |
| 고급 뽑기 | 300 / 2,700 골드 | 처음부터 | 슈퍼레어 이상 |
| 전설 뽑기 | 1,000 / 9,000 골드 | 2-10 클리어 | 유니크 이상 |
| 신화 뽑기 | 3,000 / 27,000 골드 | 5-10 클리어 | 전설 이상 |

- **연출:** 마법진이 돌다가 좋은 등급이 나오면 빛의 색이 바뀌어요 (슈퍼레어는 보라, 유니크는 주황, 전설은 금색, 신화는 무지개). 뒤집힌 카드를 눌러 하나씩 열고, 전설 이상이면 화면이 번쩍여요.
- 등급이 높을수록 능력치가 배로 강해져요 (노말의 1배 → 신화 4.5배).

### 전투
- 전투가 시작되면 동료들이 편성한 위치에 서요. **근거리 동료는 적에게 다가가서**, **원거리 동료는 사거리 안에 들어올 때까지 다가가서** 공격해요. 사제는 다친 아군에게 다가가서 치유해요.
- 웨이브 사이에는 편성 위치로 돌아오고, **전투 보너스**를 하나 골라요 (이번 판 동안만 유지).
- **용사를 포함한 파티원이 모두 쓰러지면 패배**예요. 웨이브 3개를 모두 물리치면 승리예요.
- **"도망쳐 용사!"** 버튼을 누르면 전투에서 도망쳐요. 그때까지 번 골드는 받아요.
- 같은 직업이 **3명 / 6명** 모이면 **시너지**가 켜져요:
  - 하급 병사: 공격력 증가 · 🔵 전사: 받는 피해 감소 · 🟢 궁수: 공격 속도 증가 · 🟣 마법사: 폭발 범위 증가 · 🟡 사제: 치유량 증가
- 처음 클리어하면 보상이 2배예요. 뽑은 동료는 지거나 도망쳐도 그대로 남아요.

### 스테이지 (10스테이지 × 10판 = 100판)
| 스테이지 | 이름 | 보스 (x-10) |
|---|---|---|
| 1 | 왕국의 초원 | 고블린 왕 |
| 2 | 속삭이는 숲 | 거대 늑대 |
| 3 | 버려진 광산 | 광산 골렘 |
| 4 | 사막의 유적 | 미라 왕 |
| 5 | 얼어붙은 설원 | 서리 거인 |
| 6 | 독안개 늪지 | 늪의 히드라 |
| 7 | 불타는 화산 | 화염 군주 |
| 8 | 망자의 묘지 | 리치 |
| 9 | 마왕군 요새 | 어둠의 기사 |
| 10 | 마왕성 | **마왕** (10-10, 쓰러뜨리면 엔딩) |

진행 상황(골드, 동료, 편성, 클리어한 판)은 자동으로 저장돼요.
