# 레기온 (가제): Unity 로그라이크 오토배틀러

[Legionbound](https://store.steampowered.com/app/4283360/Legionbound/)에서 영감을 받은 게임이에요. 영웅을 고용해 부대를 키우고, 같은 직업끼리 시너지를 맞추면서 오른쪽에서 끝없이 몰려오는 적으로부터 왼쪽의 **성**을 지켜냅니다.
화면은 움직이지 않는 **2D 고정 화면**이고, 옆에서 바라보는 시점이에요.

> 지금은 **프로토타입 v0.1**이에요. 그림 대신 동그라미와 네모로 표시돼요. 게임 규칙과 재미를 먼저 확인하는 단계예요.

---

## 🎮 실행하는 방법 (처음 한 번)

### 1단계: Unity 프로젝트 만들기
1. **Unity Hub**를 실행해요.
2. 오른쪽 위 **New project**(새 프로젝트)를 눌러요.
3. 템플릿에서 **Universal 2D**를 골라요. 없으면 **2D**를 골라도 돼요.
4. **Project name**에 `Legion`처럼 원하는 이름을 쓰고 **Create project**를 눌러요.
5. Unity 에디터가 열릴 때까지 기다려요. 처음에는 몇 분 걸릴 수 있어요.

### 2단계: 게임 스크립트 받기
1. 이 저장소의 GitHub 페이지에서 브랜치를 `claude/lucid-hawking-ne6ep1`로 바꿔요.
2. 초록색 **Code** 버튼을 누르고 **Download ZIP**을 눌러요.
3. 받은 ZIP 파일의 압축을 풀어요.

### 3단계: 스크립트를 Unity에 넣기
1. 압축을 푼 폴더 안의 `Assets` 폴더로 들어가면 **`Scripts`** 폴더가 있어요.
2. 이 `Scripts` 폴더를 마우스로 끌어서 Unity 에디터 아래쪽 **Project** 창의 **Assets** 위에 놓아요.
3. Unity가 잠깐 멈추는 듯하다가 오른쪽 아래에서 빙글빙글 돌아요(코드 읽는 중). 멈출 때까지 기다려요.

### 4단계: 플레이!
화면 맨 위 가운데 **▶ (Play)** 버튼을 눌러요. 다시 누르면 멈춰요.

> 💡 따로 설정할 건 없어요. ▶를 누르면 게임이 알아서 시작돼요.

## 🕹️ 게임 방법

| 조작 | 설명 |
|---|---|
| 화면 아래 버튼 | 골드로 영웅을 고용해요 (최대 50명) |
| 오른쪽 위 **속도** 버튼 | 게임 속도 1배 ↔ 2배 |

- **영웅**은 동그라미, **적**은 네모예요. 싸움은 자동으로 해요.
- 영웅은 성 앞에 진을 쳐요. 전사가 맨 앞줄, 그 뒤에 궁수, 맨 뒤에 마법사가 서요.
- 적이 성에 닿으면 성을 공격해요. **성 체력이 0이 되면 게임 오버**예요.
- 적을 쓰러뜨리면 **골드**를 얻어요.
- 웨이브를 하나 끝낼 때마다 **강화 카드 3장** 중 하나를 골라요. 판마다 카드가 다르게 나와요 (로그라이크 요소).
- 같은 직업이 **3명 / 6명** 모이면 **시너지** 효과가 켜져요.
  - 🔵 전사: 받는 피해 감소
  - 🟢 궁수: 공격 속도 증가
  - 🟣 마법사: 폭발 범위 증가
- 5웨이브마다 **거대한 적**이 나와요. 4웨이브부터는 멀리서 공격하는 **주황색 적**도 나와요.
- 최고 기록(버틴 웨이브 수)은 저장돼요.

## 🛠️ 직접 바꿔 보기 (코딩 몰라도 OK)

Project 창에서 `Scripts` 폴더의 **`HeroClass.cs`**를 더블클릭하면 코드 편집기가 열려요. 아래 같은 숫자를 바꾸고 저장(Ctrl+S)한 뒤 다시 ▶를 눌러 보세요.

```csharp
hp = 120, damage = 12, ...   // 전사의 체력과 공격력
baseCost = 10                 // 고용 가격
```

웨이브 난이도, 시작 골드, 성 체력은 **`GameManager.cs`** 위쪽의 `밸런스 숫자` 부분에 있어요. 진형 위치나 성 위치는 바로 아래 `전장 배치` 부분에 있어요.

## 📁 파일 구성

| 파일 | 하는 일 |
|---|---|
| `GameManager.cs` | 게임 전체 관리 (전장과 성, 웨이브, 골드, 고용, 시너지, 강화 카드, 화면 UI) |
| `HeroClass.cs` | 영웅 직업별 능력치 |
| `Unit.cs` | 영웅과 적의 이동, 공격, 체력 |
| `Projectile.cs` | 화살과 마법 구슬 |
| `FadeOut.cs` | 폭발 효과가 서서히 사라지게 함 |
| `SpriteFactory.cs` | 그림 없이 동그라미와 네모 모양 만들기 |
